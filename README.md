# Moderated Learning Management System

CS4433 Software Engineering individual project.

This repository contains my project documents and development files for a desktop Learning Management System (LMS).

The planned system uses C++17, a simple GUI and SQLite. It is intended to run offline on one computer. Users will have one of four roles: Administrator, Lecturer, Student or Head of Department.

The main functions are course management, assignment submissions, extensions, marking, moderation and release of results.

## Project documents

- `docs/phase-1-planning/` – Week 1: Project Management Plan
- `docs/phase-2-requirements/` – Week 2: Requirements Engineering
- `docs/phase-3-design/` – Week 3: Software Design Document

The remaining phase folders will be used as the project progresses.

## Source code

- `src/` – C++ source files
- `include/` – Header files
- `tests/` – Tests

Implementation is in progress. Build instructions are in `BUILD.md`.
