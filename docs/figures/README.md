# Browser-viewable figures for the CS4433 report

This folder contains 16 standalone SVG diagram overviews. Click any `.svg` filename in GitHub to see a preview, or open its raw URL to display the image directly without downloading a PDF.

The final report has two links for each figure: **View diagram** opens the SVG and **Source file** opens the submitted Week 1/2/3 PDF or editable CR1/deployment `.drawio` file.

**Provenance:** These SVG files are compact redrawings guided by the submitted design descriptions and the actual v1.1 design deltas. They are useful for browsing but do not replace the full original UML diagrams, exact multiplicities, detailed SQL schema or the submitted source documents.
